1. طبيعة الفريق

2. القبول والانتساب

إرسال الطلب لا يعني القبول. يبدأ الانضمام بعد موافقة المالك وتحديد القسم والرتبة والصلاحيات.

3. الواجبات

الالتزام بالاحترام والتعاون والدقة، وتنفيذ المهام المتفق عليها وإبلاغ المسؤول عند تعذر إنجازها.

4. الصلاحيات

تُمنح الصلاحيات حسب الحاجة والرتبة فقط. لا يحق للعضو مشاركة حسابه أو تجاوز حدود تفويضه.

5. السرية

حماية بيانات المستخدمين والمفاتيح والوثائق والخطط الداخلية وعدم نشرها أو نقلها دون إذن.

6. الملكية الفكرية

يجب توضيح مصدر الأعمال والمواد المستخدمة. تُحدد حقوق المساهمات كتابيًا وبما يتفق مع القانون والاتفاقات المنفصلة.

7. السلوك

يُمنع التحرش أو التمييز أو الإساءة أو إساءة استخدام بيانات الفريق أو موارده.

8. التقييم والترقية

تُراجع المساهمات والالتزام دوريًا، والترقية قرار إداري حسب الحاجة والأداء.

9. المخالفات

قد تؤدي المخالفات إلى تنبيه أو تعليق الصلاحيات أو إنهاء العضوية بعد مراجعة عادلة.

10. الانسحاب

يمكن للعضو طلب الانسحاب، وعليه تسليم المهام والمواد وإزالة أي وصول لم يعد مطلوبًا.

11. التعديلات وتسوية الخلافات

تُعلن التعديلات بوضوح، وتُعالج الخلافات أولًا بالحوار والتوثيق، مع مراعاة القانون المعمول به.

12. الموافقة الإلكترونية
